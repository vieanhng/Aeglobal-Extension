# Bundled spreadsheet libraries

- Jspreadsheet CE **4.15.0** — https://github.com/jspreadsheet/ce (MIT, see LICENSE.jspreadsheet).
- jSuites **4.9.10** — https://github.com/jsuites/jsuites (MIT, see LICENSE.jsuites).

Files copied from the version-pinned npm distributions on https://cdn.jsdelivr.net/npm/.
Scripts and styles load locally for Chrome Extension Manifest V3. Formula evaluation and automatic numeric casting are disabled for the question mover to preserve question/bank IDs as text.

API reference: https://bossanova.uk/jspreadsheet/v4/docs/quick-reference
